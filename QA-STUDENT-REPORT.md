# QA ученика — отчёт (ветка `claude/qa-student`, 2026-09-11)

## Итог: интерактивный прогон не состоялся

Сетевая политика этого окружения пропускает только GitHub. Прокси отвечает
`403` на `CONNECT` и для прода, и для Supabase:

```
niko-rolovic-site.vercel.app:443      connect_rejected (gateway answered 403)
ydcbxqrnmnbceyzqgbui.supabase.co:443  connect_rejected (gateway answered 403)
```

Поэтому **ни одного клика по порталу сделано не было**: Chromium из этого
контейнера до сайта не достучится, а локальная сборка не достучится до Supabase,
то есть данных на экранах всё равно бы не было. Пункты 1–7 и замеры «за сколько
показал содержимое / мелькнул ли скелетон» остаются невыполненными — их нужно
прогнать из окружения, где эти два хоста разрешены.

Инструмент Vercel (`web_fetch_vercel_url`) работает, но он отдаёт только HTML
одного запроса: без cookie-сессии, без JS, без кликов. Через него видно ровно
одно — неавторизованный запрос `/news` уезжает на `/register`.

Ветки `claude/qa-seed` нет, поэтому пароль к засеянному `qa-student@example.com`
взять неоткуда.

## Найдено чтением кода

Это не замена прогону — просто то, что видно по коду в областях из чеклиста.

### Починено

**Галерея: файл не-картинка уходит на сервер, большой падает молча**
(`src/app/(main)/gallery/page.tsx`)

`handleFileSelect` брал любой выбранный файл без проверок. `accept="image/*"`
фильтрует только диалог выбора — в Chrome на Android спокойно выбирается PDF, и
он реально заливался в Storage и создавал запись в `photos` со статусом
`pending`. Бакет `photos` при этом без ограничений: `file_size_limit = null`,
`allowed_mime_types = null`. Большой файл упирался в глобальный лимит проекта, и
пользователь получал `toast('Greška pri uploadu')` — ровно то «молча», которого
в задании просили избежать.

Добавил `validatePhotoFile` (проверка `image/*` и 8 МБ) на выбор файла и ещё раз
перед отправкой, плюс разбор ошибки Storage: 413 → «Slika je prevelika…»,
остальное → «Slanje nije uspjelo…». Сообщения на черногорском.

Заодно: `if (!user) return` в `handleUpload` выходил, не сбросив `uploading`, —
кнопка навсегда оставалась в «Šalje se...». Теперь сбрасывает и объясняет, что
сессия истекла.

Проверено только `npm run build` — прокликать в браузере возможности нет.

### Не чинил, стоит посмотреть

**Скелетоны там, где ждали SSR.** По таблице маршрутов из сборки на сервере
рендерятся `/news`, `/events`, `/lectures`, `/lectures/[subject]`,
`/lectures/[subject]/[id]`, `/schedule`. А `/gallery`, `/game`, `/profile`,
`/grades`, `/tournament`, `/ednevnik` — статические оболочки, которые тянут
данные уже в браузере; у галереи и игры прямо `useState(true)` под загрузку.
То есть скелетон на этих экранах мелькать будет, и это ожидаемо, а не баг —
но если перевод на серверную отрисовку задумывался сплошным, эти шесть до него
не доехали.

**Лимит на размер лучше продублировать на бакете.** Моя правка клиентская, её
обходит любой прямой запрос к Storage. `file_size_limit` и
`allowed_mime_types` у бакета `photos` стоит выставить и на сервере. Не стал
менять сам — это конфиг боевого хранилища, не экран ученика.

**`photo_hearts` — мёртвая таблица.** В `src/` не используется (сердечки в
галерее идут через `photo_likes`). У неё есть INSERT/UPDATE-политики, но нет
DELETE: если её когда-нибудь подключат, снятие сердечка будет тихо не работать.

### Посмотрел, претензий нет

- **Пагинация новостей** (`src/lib/news-data.ts`): `range(from, from + pageSize)`
  берёт на строку больше, чтобы узнать про следующую страницу, и срезает её —
  ни дублей, ни дыр на границе. Счётчик лайков считается из всех строк
  `news_likes`, и RLS (`likes_read`: любой authenticated) это разрешает, так что
  после перезагрузки цифра должна сойтись. От быстрых повторных нажатий стоит
  дебаунс 300 мс плюс `likingIdsRef`, откат оптимистичного апдейта при ошибке
  есть.
- **События**: `prevMonth`/`nextMonth` переносят год через границу правильно.
- **Квиз**: по истечении таймера вопрос помечается отвеченным, `selected = -1`,
  балл не начисляется; `resetQuiz` сбрасывает всё.
- **Калькулятор оценок**: на пустом наборе `average = 0` → «Nema ocjena», «---»,
  кольцо пустое; на одних пятёрках → 5.00, кольцо полное, «Odlican». Формула
  `offset = circumference * (1 - avg/5)` верна.
- **eDnevnik**: без токена показывает инструкцию, при ошибке рисует текст ошибки,
  пустого экрана нет. Edge-функция `ednevnik-proxy` задеплоена и активна.
